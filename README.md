# Laravel Todo
A simple Todo app with Laravel and Vue3
## Install
* Clone the repo
* Copy .env.example and rename to .env. Set your env variables: `VITE_API_URL=http://127.0.0.1:8000`
* Go to the project directory and run `composer install` then `npm install`
* Run `php artisan migrate`
* Launch the servers with `npm run dev` and `php artisan serve` on a different terminal

Go to http:127.0.0.1:8000 to see the app
