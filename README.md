# Laravel Todo
A simple Todo app with Laravel and Vue3
## Install
* Clone the repo
* Copy the `.env.example` file and rename it to `.env` then set your env variables: `VITE_API_URL=http://127.0.0.1:8000/api`
* Go to the project directory and run `composer install`, `php artisan migrate` and then `npm install`
* Launch the servers with `npm run dev` and `php artisan serve` on a different terminal

Go to http:127.0.0.1:8000 to see the app
